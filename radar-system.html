Arduino Radar System

Why i built this

I built this to combine three components: sensor, servo, and output into one system that actually communicates, instead of each part working alone.

It also became my test for scalability: more sensors, a proper mapping display, or wireless data transmission are all next steps from the same base.

Components

Arduino

LEDs

HC-SR04 (sensor)

Resistors

LCD 16x2(I2C)
