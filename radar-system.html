Why i built this

I wanted to try out an ultrasonic sensor and see how it works, close to how bats use echolocation, while also learning to control a servo.

This project doubles as a base for bigger applications — automation, IoT, object detection, or even something closer to a defense radar system.

How it works

The servo sweeps the ultrasonic sensor from 0 to 180 degrees, then back from 180 to 0. At each angle, the sensor sends out an ultrasonic wave and times how long it takes to bounce back, converting that into a distance reading.

The angle and distance show on the LCD. The Arduino also runs a danger meter: the closer the object, the fewer LEDs light up, down to a single red LED at close range, and the farther away, the more LEDs light up, up to all 5 at a safe distance. Exact thresholds are in the code, lines 67-100.

Steps to build

1. Gather all the components. Arduino, HC-SR04 ultrasonic sensor, servo motor, 5 LEDs, resistors, I2C LCD, breadboard, jumper wires.

2. Wire the ultrasonic sensor: VCC to power, GND to ground, trig and echo to digital pins 3 and 2.

3. Wire the servo: power, ground, and signal to digital pin 4.

4. Wire the 5 LEDs to digital pins 5 through 9, each through a resistor.

5. Wire the I2C LCD: SDA and SCL to the Arduino's I2C pins, VCC to 5V, GND to ground.

6. Set up pin modes, attach the servo, and initialize the LCD with a startup message in setup().

7. Code a loop that sweeps the servo from 0 to 180 degrees, then back from 180 to 0, in 10-degree steps.

8. At each angle, trigger the ultrasonic sensor and calculate distance from the echo pulse duration.

9. Set distance thresholds and light 1 to 5 LEDs based on proximity, fewer LEDs when close, more when far.

10. Display the current angle and distance on the LCD and Serial monitor.
