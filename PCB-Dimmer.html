Why i built this

This is my first PCB design project. I wanted to learn KiCad and figure out how to build a working circuit from scratch, so future Arduino projects can move from breadboard sprawl to something simpler and more compact.

With this project, i learned to calculate component values, routing, assigning footprints, and generating manufacturing files.

How it works

The potentiometer acts as a variable resistor, which controls the amount of current flowing to the LED. By adjusting the potentiometer, you can dim or brighten the LED.

The resistor is used to limit the current flowing through the LED, preventing it from burning out. The 2-pin connector is used to connect the battery to the circuit.

Steps to Build

1. Define the components — 9V supply, 5mm LED (~2V forward voltage, ~20mA), 330Ω resistor, 1kΩ potentiometer.

2. Draw the schematics, J1 to +9V/GND, then through RV1, R1 (330Ω), and D1 back to GND, using the real (non-SPICE) potentiometer symbol.

3. Add a PWR_FLAG on +9V and one on GND.

4. Run electrical rule check (ERC) until there are 0 violations.

5. Assign footprints for all components.

6. Update the PCB layout from the schematic, draw the edge cuts, and arrange the components.

7. Route all traces on the front copper layer, from J1 through RV1, R1, and D1.

8. Add a filled ground zone on the front copper layer, assigned to the GND net.

9. Run design rule check (DRC) until there are 0 errors, then generate the Gerber and drill files.
