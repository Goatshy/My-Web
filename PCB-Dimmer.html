9V LED Dimmer PCB

Input

9V Battery

Control

Potentiometer

Output

LED

Why i built this

I built this to learn about PCB design and to learn how to use KiCad as my design tool for PCB design.

It also became my first ever PCB design project. I learned to calculate component values, routing, assigning footprints, and generating manufacturing files.

How it works

The potentiometer acts as a variable resistor, which controls the amount of current flowing to the LED. By adjusting the potentiometer, you can dim or brighten the LED.

The resistor is used to limit the current flowing through the LED, preventing it from burning out. The 2-pin connector is used to connect the battery to the circuit.

Steps to Build

1. Design the circuit schematic in KiCad.

2. Assign footprints to the components and update the PCB layout from the schematic.

3. Run electrical rule check (ERC) to make sure there are no errors.

4. Draw the physical outline (border) of your circuit board.

5. Route the connections and create a ground plane.

6. Run design rule check (DRC) to make sure there are no errors.

7. Generate the Gerber files and drill files for manufacturing.

Components
