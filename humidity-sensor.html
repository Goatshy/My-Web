Arduino Temperature & Humidity Sensor

Sensor

DHT22

Thresholds

6 LED states

Output

I2C LCD

Why i built this

I wanted to understand how a sensor sends data to a microcontroller and how other components react when that data changes. This is also a solid base for automation or IoT work — detect a shift in temperature or humidity, process it, and get other components to respond at set thresholds.

I switched to an I2C LCD for this build. A standard 16x2 LCD needs 6-12 pins wired directly to the Arduino; I2C cuts that down to two data lines (SDA and SCL) plus power and ground. Fewer wires, less to get wrong, and I wanted to learn how I2C communication actually works.

How it works

TThe DHT22 sensor reads temperature and humidity from the environment and sends that data to the microcontroller. Based on where each value falls, the Arduino lights up an LED to show the range.

Temperature uses the top 3 LEDs — cold, warm, hot, left to right. Ranges are set in the code, lines 63-77.

Humidity uses the bottom 3 LEDs — dry, normal, humid, left to right. Ranges are set in the code, lines 80-94.

Steps to build

1. Gather all the components — Arduino, DHT22 sensor, I2C LCD, 6 LEDs, resistors, breadboard, jumper wires.

2. Wire the DHT22 sensor: VCC to 5V, GND to ground, and the data pin to digital pin 2 on the Arduino

3. Wire the I2C LCD: SDA and SCL to the Arduino's I2C pins, VCC to 5V, GND to ground.

4. Wire the 6 LEDs with resistors to separate digital pins — 3 for temperature (cold, warm, hot) and 3 for humidity (dry, ideal, high).

5. Include the DHT library and initialize the sensor (DHT dht(DHTPIN, DHTTYPE)), then initialize the LCD with its I2C address (LiquidCrystal_I2C).

6. Code the sensor to read temperature and humidity values in loop(), using dht.readTemperature() and dht.readHumidity().

7. Code the LCD to display the live readings.

8. Set threshold variables for each range (cold, ideal, hot, dry, optimal, humid) and use if-else statements to turn on the matching LED based on the sensor values.
