Arduino Temperature & Humidity Sensor

Why i built this

This project came from wanting to understand how a sensor and a display sync up in real time, not just read a static value once.

I built it to scale past a single readout: logging data over time, adding more sensors, eventually pushing it to a network instead of just a screen.
