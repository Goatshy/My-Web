Automatic Night Light PCB

Input

9V Battery

Control

Light Dependent Resistor (LDR)

Output

LED

Why i built this

I built this to learn more about the principles of automatic systems and to explore more components.

With this project, i learn how components like comparator and transistor process an input signal and control the output.

How it works

The LDR (Light Dependent Resistor) changes its resistance based on the amount of light it receives. When it's dark, the resistance is high, and when it's bright, the resistance is low.

When the LDR detects low light (darkness), its resistance increases, which triggers the comparator to turn on the LED. Conversely, when the LDR detects high light (brightness), its resistance decreases, and the LED turns off.

Steps to Build

1. Gather the components for the schematic.

2. Connect the components to each other and also to a power source or ground.

3. Run electrical rule check (ERC) to make sure there are no errors.

4. Update the PCB layout from the schematic.

5. Arrange the components on the PCB and Draw the physical outline (border) of your circuit board.

6. Route the connections and create a ground plane and run design rule check (DRC) to make sure there are no errors

7. Switch to a different layer to connect the blocked routes.

8. Add filled zone and generate the Gerber files and drill files for manufacturing
