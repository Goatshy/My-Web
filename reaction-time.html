Arduino Reaction Time Test

Inputs

1 button

Resolution

ms

Output

LCD + buzzer

Why i built this

I wanted to see how a button, an LED, and a timer actually talk to each other on one board, not just wire a single sensor and call it done.

The project also help me study how to generate a random delay and learn to measure time in milliseconds.

How it works

The Arduino waits for a random time, then turns off the green LED and starts the timer. The player must press the button as fast as possible. The Arduino stops the timer and displays the reaction time on the LCD.

If the player presses the button before the green LED turns off, the LED will reset and the player will have to wait for the next round.

Steps to build

1. Gather all the components.

2. Connect the Arduino to the breadboard.

3. Wire the LEDs, button, and buzzer to each other and to the Arduino.

4. Connect the LCD to the Arduino.

5. Code the delay between the LED's and generate the random time for the green LED.

6. Make the LED's reset after each round or if the button is pressed too early.

7. Measure the time between the green LED turning off and the button being pressed.

8. Display the reaction time on the LCD.
