Arduino Reaction Time Test

Inputs

1 button

Resolution

ms

Output

LCD + buzzer

#1

Why I built this

I wanted to understand how timers work on Arduino and how to generate a random delay instead of a fixed one.

I also wanted to practice measuring time in milliseconds and get comfortable with basic components — button, LED, resistor, LCD. This is my first Arduino simulation project, so it's the starting point before I try anything more complex.

#2

How it works

The red and yellow LEDs turn off after a fixed delay. The green LED turns off after a random delay between 0.9 and 4.5 seconds. The player has to press the button the moment the green LED turns off.

If the player presses the button before the green LED turns off, the LED will reset and the player will have to wait for the next round. Once the green LED turns off, the timer starts. Pressing the button stops it and the reaction time shows on the LCD.

#3

Components

Arduino LEDs Button Resistors Buzzer Wires Breadboard LCD 16x2

#4

Click ▶ in the simulator below to run it live. Adjust the split screen to your preference. Wait until the green LED turns off, then click the button (near the yellow LED).

#5

Steps to build

  1. Gather all the components.
  2. Set up the LEDs and assign their delay values — fixed for red and yellow, random for green.
  3. Wire the button: connect two pins to power and ground, then connect the ground pin to a digital input on the Arduino.
  4. Work on the LED logic and time measurement — start the timer when the green LED turns off, stop it when the button is pressed.
  5. Connect the LCD and display the reaction time.
  6. Add the reset logic so the LEDs restart if the button is pressed too early.
  7. Add a buzzer to give feedback when the button is pressed.
  8. Display the reaction time on the LCD.
